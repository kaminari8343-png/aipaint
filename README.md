# うちゅうUMAずかん

小学1年生向けの、宇宙とUMAのクイズ図鑑ゲーム（iPad想定）。

- ヒントカードを読む（音声読み上げ）→ クイズに答える → 図鑑カードをゲット
- カード32枚：宇宙18枚 + UMA14枚、全部ひらがな中心
- 🔢 さんすうロケット：10までのたし算・ひき算
- 🈴 かんじクエスト：小1の漢字の読み（間違えるとヒント）
- 🎮 ミニゲーム：☄️よけゲーム（指でロケットを動かす）／🦕UMAつかまえゲーム
- ゲットしたカードで遊べる「シルエットゲーム」
- 進捗・ベストスコアは端末内（localStorage）に保存。広告・課金・通信なし

## 遊び方
`index.html` をブラウザで開くだけ。iPadでは Safari で開き、共有ボタン →「ホーム画面に追加」で全画面アプリのように使えます。
